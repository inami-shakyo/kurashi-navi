掲載内容のファクトチェックを行ってください。$ARGUMENTS

## 手順

### 1. まず未確認の記述を一覧する

```
python3 .claude/hooks/factcheck_scan.py report
```

### 2. 範囲を区切る

**一度に全54制度をやろうとしないこと。** 範囲の指定がなければ、
下の優先順から5〜8制度ぶんだけを選んで、今回の対象として最初に宣言してください。

優先順：

1. **`meyasu` を持つ制度**（具体的な金額・基準が載っているもの。改定されやすい）
2. **電話番号** — `ENTRY_CONTACTS`（入口の窓口一覧）と各制度の `contact` の両方。
   **同じ窓口の番号が2か所で一致しているかも必ず見ること。** 食い違っていたら報告する
3. **年度で変わる額**（生活保護基準、住宅扶助、各種手当、貸付の上限など）

### 3. 一次情報と突き合わせる

優先順は CLAUDE.md のとおり。①稲美町公式サイト（`town.inami.lg.jp`）／稲美町社協
②兵庫県・東播磨県民局・加古川健康福祉事務所 ③所管省庁（厚生労働省・こども家庭庁など）。

- **まとめサイト・他自治体のページ・検索結果のスニペットだけでは根拠にしない。**
  数字はページ本文で現物照合する。
- 確認できた値は `docs/fact-log.md` に出典URLと確認日つきで追記する。
- `DATA_ASOF` より新しい改定が見つかったら、本文と `DATA_ASOF` の両方を直す。
- 確認できなかったものは**推測で埋めず**、本文に `【要確認】` を付ける。
- ネットに繋がらないときは、確認できなかったものとして扱う。

### 4. 報告は3つに分けて書く

- **✅ 確認して正しかったもの** … 項目／値／出典URL
- **🔧 誤りを修正したもの** … 項目／旧値 → 新値／出典URL
- **⚠️ 確認できず `【要確認】` にしたもの** … 項目／なぜ確認できなかったか

今回見ていない範囲があれば、最後に「次回の対象」として書き添えてください。
